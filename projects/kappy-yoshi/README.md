# Kappy × Yoshi先生 プロジェクト

Yoshi先生の講話（動画・音声）を素材として整理・蓄積するフォルダ。

## シリーズ構成：「気虚・血虚・気滞」で未病を治す

ヨシクリニックの体の見立ての3つの基準。

| # | テーマ | 内容 | 状態 |
|---|---|---|---|
| 01 | **気虚**（見えないもの） | 思考＝エゴの声を観察し「今ここ」にいる。直感に従う | 収録済み（素材未受領） |
| 02 | **血虚**（見えるもの） | 栄養 — オートファジーとATP | ✅ 整理済み → [notes/02-血虚-栄養.md](notes/02-血虚-栄養.md) |
| 03 | **気滞**（流れ） | 滞りなく流す。マッサージ・整体・骨格 | 次回収録予定 |
| 02b | 血虚 続編 | 脂質・タンパク質量など深掘り（先生が「もう1本撮りたい」と発言） | 候補 |

## フォルダ構成

```
projects/kappy-yoshi/
├── README.md        ← この一覧
├── notes/           ← 回ごとの整理ノート（要点・構成・用語・確認事項）
└── transcripts/     ← 文字起こし原文（受領したまま保存）
```

## 素材の追加方法

新しい講話のWordファイルや文字起こしを渡してもらえれば、同じ形式で `notes/` と `transcripts/` に追加し、この表を更新します。
