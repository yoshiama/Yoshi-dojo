# 発信戦略と収益化

YouTubeを本拠地に、ショート・インスタで世界へ広げ、最終的に事業として回る形を作るための整理です。

---

## 1. 立ち位置（他と何が違うか）

> **「日本人整体師が、スペインで見つけた“頑張らない長寿法”」**

この組み合わせは、ほかの健康チャンネルとほとんど重なりません。

| 強み | なぜ効くか |
|---|---|
| **日本 × スペイン** | 海外では日本式の健康法（腹八分目、生きがい、森林浴など）と地中海式の暮らし（シエスタ、食事をゆっくり楽しむ）の両方が人気。その両方を体験している人は少ない |
| **頑張らない** | 世界的に長寿・若返りブームだが、主流は「計測して、サプリを大量に飲んで、厳しく管理する」ストイック路線。それに疲れた人への**逆張り**になる |
| **先生自身が燃え尽きた経験者** | 完璧主義で心身を壊した実体験（『夢の地スペイン』）は、どんな理論より信頼される |
| **Kappyさんという分身** | 視聴者が「自分のことだ」と思える。会話形式は一人語りより続けて見てもらいやすい |
| **心と体の両方** | 栄養だけ・運動だけ・メンタルだけのチャンネルが多い中、気虚・血虚・気滞でまとめて扱える |

## 2. 今の流れ（トレンド）とどう乗るか

※ 2026年11月時点の見立てです。流行りは変わるので、定期的に見直します。

| 流れ | 内容 | Yoshi Dojoでの乗り方 |
|---|---|---|
| **長寿・健康寿命ブーム** | 「寿命」より「健康でいられる期間（ヘルススパン）」への関心が世界的に高い | シリーズの中心テーマそのもの。英語では「healthspan」をタイトルに使う |
| **燃え尽き・働き方の見直し** | 燃え尽き症候群、日本では「静かな退職」、海外では「ゆるく生きる」志向 | Kappyさん＝この層の代表。「頑張らない」がそのまま刺さる |
| **日本式の健康法への関心** | 腹八分目（hara hachi bu）、生きがい（ikigai）、日本式ウォーキングなどが海外で話題になりやすい | オートファジーの回を「Hara Hachi Bu」の切り口で世界向けショートにする |
| **地中海式の暮らし** | 地中海食、シエスタ、家族とゆっくり食べる文化 | スペインでの先生の日常を見せる回（型F）。日本の視聴者には「憧れ」、海外には「日本人の目から見たスペイン」 |
| **細胞・ミトコンドリア・断食** | オートファジー、ATP、間欠的断食、タンパク質が注目されている | 第2回の素材がそのまま使える。ただし「頑張らない版」として差別化 |
| **会話形式の動画ポッドキャスト** | 対談をYouTubeで見る・聞く人が増えている | 本編は対談形式でぴったり。ながら聞きされやすい |
| **自動翻訳・多言語字幕** | YouTubeの自動吹き替えや多言語字幕で、日本語の動画でも海外に届きやすくなっている | アプリと同じく多言語展開。まずは日本語・英語・スペイン語 |
| **健康経営（日本）** | 社員の健康に投資する会社が増えている | Kappyさん＝会社員。**企業研修**として売れる（4章） |

## 3. 配信の仕組み（1本の撮影から何本も作る）

```
本編（YouTube・8〜15分の対談）……週1本
   │
   ├─ ショート 3〜5本（30〜60秒）……YouTubeショート
   │     ├─ 同じものをインスタのリール、TikTokにも
   │     └─ 英語・スペイン語の字幕版も
   │
   ├─ インスタのカルーセル（画像5〜8枚）……例え話・思い込みの表をそのまま図に
   │
   └─ 本編のまとめを、LINE・メールでお知らせ
```

### ショートにしやすい場面（撮影時に意識して入れる）
- **思い込みをひっくり返す瞬間**（企画書5-④の表）
- **Kappyさんの「えっ！？」という驚き**
- **体感ワーク**（握りこぶしなど。言葉が分からなくても伝わるので海外向き）
- **今日のひとつ**（最後の決めゼリフ）
- **先生の燃え尽き体験の告白**（感情が動く場面は広まりやすい）

### 本編タイトルの付け方（例）
| 型 | 日本語 | 英語 |
|---|---|---|
| 思い込みを否定 | 「バランスよく食べる」が危ない理由 | Why "eat balanced" isn't enough |
| 体験談 | 完璧主義で体を壊した整体師が、スペインで見つけたこと | I burned out in Japan. Spain taught me this. |
| 数字 | 40代から健康寿命を延ばす3つの習慣 | 3 habits for a longer healthspan after 40 |
| 日本の知恵 | 腹八分目が細胞を若返らせる仕組み | Hara Hachi Bu: the Japanese rule your cells love |

## 4. 収益化（お金の流れ）

無料で価値を届けて信頼を作り、必要な人を有料のサービスへ案内する、という段階を作ります。

| 段階 | 中身 | 価格帯の目安 | 既存の資産 |
|---|---|---|---|
| **0. 無料で知ってもらう** | YouTube本編、ショート、インスタ | 無料 | ― |
| **1. つながる** | LINE（日本）、メール・WhatsApp（海外）に登録してもらう。登録特典として「黄金の1週間チェックシート」などを配る | 無料 | ― |
| **2. 手軽に試す** | 本『夢の地スペイン』、アプリ「Yoshi Dojo」、YouTubeメンバーシップ | 数百〜数千円 | ✅ 本（Kindle）、✅ アプリ（7言語） |
| **3. しっかり学ぶ** | Yoshiメソッド3ヶ月オンラインプログラム（イケおじ育成プログラムを発展させたもの）。グループセッション付き | 数万円〜 | ✅ イケおじ講座の設計 |
| **4. 深く関わる** | 個別セッション、スペインでの整体、**スペインでのリトリート（滞在型合宿）** | 高価格 | ✅ ヨシクリニック |
| **4'. 会社向け** | **企業研修・健康経営セミナー**（日本の会社員向け。「Kappyさんの会社」に売るイメージ） | 1回あたりの単価が高い | ― |
| ＋ 広告収入 | YouTubeの広告収入（条件を満たしたら） | ― | ― |

### 考え方のポイント
- **一番大きくなりやすいのは段階3・4・4'。** 広告収入は「おまけ」と考え、動画は「信頼を作って段階1につなげる入口」と位置づける
- 動画の最後と概要欄には、毎回必ず**段階1（LINE・メール登録）への案内**を入れる
- **企業研修**は、Kappyさんのシリーズそのものが「営業資料」になる。40代社員の燃え尽き・健康は会社の困りごとでもある
- **スペインのリトリート**は世界中の視聴者が対象になり、単価も高い。チャンネルが育った段階で検討
- スポンサー（サプリ・食品など）は信頼を損ねやすいので、受けるなら慎重に。先生が本当に使っているものだけ

## 5. 目標の目安（最初の1年）

| 時期 | やること | 見る数字 |
|---|---|---|
| 1〜3ヶ月 | シーズン1（全10話）を撮って公開。ショートで反応を見る | どのショートがよく見られたか、登録者数 |
| 4〜6ヶ月 | 反応が良かったテーマを深掘り。LINE・メール登録の導線を整える | LINE・メール登録数 |
| 7〜9ヶ月 | 3ヶ月プログラムの第1期を募集 | 申込数 |
| 10〜12ヶ月 | 英語・スペイン語向けを強化。企業研修の案内を開始 | 海外からの視聴の割合、問い合わせ数 |

## 6. 気をつけること

- **YouTubeの医療に関するルール**：病気の治療について、公的な医療機関の見解と食い違う内容（「薬をやめても大丈夫」など）は動画が削除される恐れがある。企画書9章の「表現のルール」を必ず守る
- 数値や研究の話は「約」「目安」「〜という考え方もある」を付ける
- 海外配信では、国ごとに健康食品やサプリの扱いが違うので、特定商品の効果をうたわない
