# Kappy × Yoshi先生　会話シリーズ企画書

会話の案を作るときの土台です。ここにある**登場人物・Kappyさんの変化の段階・例え話・型**を組み合わせると、いろいろなバージョンの会話を作れます。

---

## 1. コンセプト

**楽しく聞いているうちに、健康寿命と自然医学の考え方がいつのまにか身についている会話シリーズ。**

- 主人公はKappyさん。現代医学にどっぷり頼っていたKappyさんが、Yoshi先生との会話を通して**本来の医療＝Yoshiメソッド**に目覚めていく
- 視聴者はKappyさんと一緒に驚き、笑い、納得しながら、自然と考え方が変わっていく
- **現代医学を否定しない。** いいところは取り入れ、上手に使う。そのうえで「病気になる前に、自分で整える」力を取り戻す

### タイトル（決定案）
| | 日本語 | 世界向け（英語） |
|---|---|---|
| チャンネル名 | **Yoshi Dojo**（アプリ・本と名前をそろえる） | Yoshi Dojo |
| シリーズ名 | **頑張らない健康道場 〜Kappyの目覚め〜** | **Stop Hustling, Start Healing — Kappy Wakes Up** |
| 関連：著書 | 『夢の地スペインで絶望した僕に奇跡が起きた話』 | 英語版（翻訳中）：**YURUMU — The Art of Letting Go** |
| 一言キャッチ | 日本人整体師がスペインで見つけた、心と体を整える本当の健康 | A Japanese healer in Spain on living long without trying so hard |

選んだ理由：「頑張らない」はYoshiメソッドの核であり、ストイックな健康法に疲れた人が増えている今の流れにも合うため。「道場」はアプリ名とつながり、海外でも「Dojo」で通じます。

別案：「病院に行く前に聞く話」「サラリーマンKappy、本来の自分に目覚める」「イケおじへの道」

### 現代医学とYoshiメソッドの関係（シリーズ全体で守る立ち位置）

> **現代医学は消防隊。Yoshiメソッドは火が出にくい家づくり。**
> 火事（ケガ・急な病気）のときは迷わず消防隊（病院）を呼ぶ。でも、毎日の暮らしで火が出にくい家にしておくのは自分にしかできない。どちらも大事。

この例えを第1話で出して、以降の回でも繰り返し使います。

## 2. 登場人物

### Kappyさん（聞き手・視聴者の代わり）
- **人物像**：40代くらいの会社員。健康寿命のことがちょうど気になり始めた年齢
- **今の状態**：本来の自分にまだ気づいていない。言われた仕事をこなす毎日
- **心の奥の本音**：「本当は好きなことをして生きたい。しかも健康になりたい」。でも、そう思っていいのか、まだ半信半疑
- **出発点（体）**：体の不調は病院と薬で治すもの。健康情報はテレビとネット頼み。健康診断の数値に一喜一憂する
- **視聴者との重なり**：日本の40〜50代の会社員、そして世界中の「燃え尽きかけている働く人」がKappyさんに自分を重ねられるようにする
- **役割**：視聴者が思う素朴な疑問・ツッコミ・反論を代わりに言う。驚く、体験する、メモする
- **口ぐせ案**
  - 「え、病院で言われたのと違うんですけど！？」
  - 「ちょっと待って、それメモします」
  - 「……あれ？ 今ちょっと楽になったかも」
- **変わっていくところ**：「治してもらう」→「自分で整える」。「頑張る健康法」→「力を抜く健康法」
- **変わらないところ**：必要なときは病院に行く。検査もうまく使う

### Yoshi先生（案内役）
- 整体師。ヨシクリニック主宰。20年以上の経験。今もサッカーを楽しむ「イケおじ」の実例
- **過去（著書『夢の地スペインで絶望した僕に奇跡が起きた話』）**：日本的なストイックな働き方と完璧主義で、**自分自身が心と体を壊した**。だからこそ、頑張りすぎている人の気持ちが分かる
  - 早稲田大学でスポーツ医学、北京中医薬大学で中医学 → **西洋と東洋の両方を学んだ人**
  - マドリードで開業し「努力が足りない」と働き詰め → 29歳、市バスの中で突然の激しい動悸（のちにパニック障害と分かる）。施術も仕事もできなくなる
  - 奥様との「思い込みを書き出す」セッションで、「ねばならない」を手放し、「ここにいるだけで合格」と気づいて回復
  - 力を抜いてから、サッカー日本代表選手や世界的大企業のトップのケアにつながる
  - 詳しくは [ref-夢の地スペイン-エッセンス.md](ref-夢の地スペイン-エッセンス.md)
- **今**：スペインで暮らし、自分で作った**Yoshiメソッド**で「心と体を整えることが本当の健康」だと伝えている
- **Kappyさんとの関係**：「昔の自分を見ているよう」。上から教えるのではなく、**同じ道を通ってきた先輩**として話す。これがシリーズの信頼感の源になる
- **話し方**：押しつけない。例え話が上手。体感させてから説明する
- **口ぐせ案**
  - 「頑張らなくていいんですよ」
  - 「鵜呑みにしないで、まず自分の体で感じてみてください」
  - 「病院は病院で、すごく大事なんです。そのうえで、です」

## 3. Kappyさんの目覚めの5段階（シーズン全体の流れ）

各話はどこかの段階に置きます。段階が進むにつれてKappyさんのセリフが変わっていくのが、このシリーズの見どころです。

| 段階 | Kappyさんの状態 | よく出るセリフ | 扱うテーマ |
|---|---|---|---|
| ① 依存 | 薬と病院とネット情報がすべて。仕事も言われたことをこなすだけ | 「薬飲めば治るでしょ？」「好きなことなんて、定年してからですよ」 | 健康寿命と平均寿命の違い、未病 |
| ② 疑問 | 「あれ？ それだけじゃないのかも」 | 「じゃあ何で私、ずっとだるいの？」 | カロリー中心の栄養の限界、情報があふれすぎ問題 |
| ③ 体感 | 体で感じて驚く | 「え、今ちょっと楽になった！」 | 力を抜く・呼吸・姿勢・空腹を感じる |
| ④ 統合 | 現代医学とYoshiメソッドの使い分けがわかる | 「病院は消防隊、家づくりは自分」 | 検査の上手な使い方、気虚・血虚・気滞の全体像 |
| ⑤ 実践・伝える | 自分の軸ができて、好きなことにも踏み出す。人に話したくなる | 「家族にも教えたい」「好きなこと、今から始めていいんですね」 | 自分が元気になると家族・職場・日本が元気になる |

**シリーズの裏テーマ**：体の目覚めと一緒に、Kappyさんが「本来の自分」にも目覚めていく。健康を取り戻すことは、好きなことをして生きる力を取り戻すこと。Yoshi先生自身がその実例。

## 4. Yoshiメソッドの中身（会話で伝える内容）

### 大元：禅（鈴木大拙）
すべての土台。分けて考えること（分別）は否定せず、それにとらわれない位置（無分別の智）から今に生きる。禅には努力がいらない（砂場の子ども）。自由とは「自らに由る」＝あなたがあなたらしく生きること。禅の状態で食べ・動き・眠ることが本来の予防医学。
→ 詳しくは [00-禅-Yoshiメソッドの土台.md](00-禅-Yoshiメソッドの土台.md)

**Kappyさんの目覚めの決定打**：「好きなことをして生きたい」はわがまま？ → 「欲望に縛られるのがわがまま。あなたらしく生きるのが自由。松は松でいい」

### 全体の枠組み：気虚・血虚・気滞
| | 何のこと | 一言でいうと | 素材 |
|---|---|---|---|
| **気虚** | 見えないもの（心・思考） | 頭の中のおしゃべり（エゴ）を静めて「今ここ」にいる | 収録済み・素材待ち |
| **血虚** | 見えるもの（体・細胞・栄養） | 細胞が元気に働ける栄養をとる（オートファジーとATP） | ✅ 第2回 |
| **気滞** | 流れ | 心は執着を手放す、体は姿勢・運動・マッサージで流す | 次回収録 |

### シリーズを通したメッセージ
1. 健康寿命は「長生き」ではなく「**楽しめる時間を延ばす**」こと
2. **頑張らない。** 力を入れるほど体は固まり、流れが止まる
3. **人それぞれ。** まず自分の体を知る
4. **鵜呑みにしない。** 自分の軸を持てば情報に振り回されない
5. **まず1週間**（黄金の1週間）
6. 自分が元気になれば、**周りも元気になる**

## 5. 「いつのまにか身につく」ための仕掛け

### ① 例え話の引き出し（そのまま会話で使える）
| 伝えたいこと | 例え |
|---|---|
| 現代医学とYoshiメソッドの関係 | 消防隊と、火が出にくい家づくり |
| 健康寿命 | 人生のフルマラソン。ゴールまで**自分の足で走って楽しめるか** |
| 未病 | 「まだ雨漏りしていないけど、屋根の瓦がずれている」状態 |
| オートファジー | 伊勢神宮の建て替え／細胞が自分で部屋を片付けてリサイクルする |
| ATP | 細胞の発電所。糖だけだと豆電球、タンパク質・ビタミンB・鉄がそろうと大型発電所 |
| エゴ（思考） | 頭の中のラジオ。「未来の不安チャンネル」と「過去の後悔チャンネル」ばかり流れている |
| 気滞 | 川の流れ。ゴミがたまると淀む。マッサージは川掃除 |
| 頑張りすぎ | 握りこぶし。ぎゅっと握ると腕まで固くなって血が通いにくい |
| 検査の数値 | 車の警告ランプ。点いたら整備工場（病院）へ。でも毎日の運転の仕方とメンテナンスは自分次第 |
| 情報に振り回される | 地図アプリを10個同時に開いて迷子になっている |
| 不安 | 失敗行きのベルトコンベアに乗っている。乗り換えればいい（著書） |
| 頑張りすぎ（その2） | 溺れそうなときほど必死に泳ぐ。力を抜くと体は浮く（著書） |
| 思い込み | 正しさの鎧。着たままでは深呼吸できない（著書） |
| 忙しさ | 「忙」は心を亡くすと書く（著書） |
| 人生 | 硬い岩ではなく、柔らかい水（著書） |

### ② 体感ワーク（画面の前で一緒にできる）
- **握りこぶしワーク**：思いきり握る → 腕の固さを感じる → ふっと緩める → 「頑張らない」を体で理解
- **呼吸ワーク**：3回ゆっくり吐く → 頭のラジオが静かになるのを感じる（気虚の回）
- **姿勢ワーク**：猫背と良い姿勢で深呼吸を比べる（気滞の回）
- **空腹チェック**：「最後にお腹がグーッと鳴ったのはいつ？」（オートファジーの回）
- **ベルトコンベアワーク**：不安のベルトに気づく → 「本当に100％？」と問う → 欲しい未来を選び直す（著書）
- **青いもの・赤いものワーク**：10秒で青いものを覚え、赤いものを聞かれると思い出せない → 盲点を体験（著書。海外向けショートに最適）
- **梅干しワーク**：想像するだけで唾が出る → 脳は想像を現実と受け取る（著書）

### ③ 毎回の決まりごと（くり返しで記憶に残す）
- **オープニングの合言葉**（案）：Kappy「今日も頑張らずに！」 Yoshi「整えていきましょう」
- **今日のひとつ**：最後に一つだけ持ち帰る行動（例：「今日は1回だけ、空腹を感じてから食べる」）
- **Kappyの目覚めメーター**：回ごとにKappyさんの変化をひとことで振り返る

### ④ 思い込みをひっくり返す（驚きは記憶に残る）
| よくある思い込み | Yoshiメソッドでは |
|---|---|
| バランスよく食べれば大丈夫 | 何をどれだけ、が人によって違う。細胞が何を必要としているかで考える |
| 健康のためには頑張らないと | 頑張るほど体は緊張する。力を抜くほうが続く |
| 断食すればやせて健康 | 空腹の時間は大事。でもエネルギー不足は逆効果。腹八分目 |
| 数値が正常なら健康 | 数値は大事なサイン。でも「なんとなくだるい」も体からのサイン |
| 健康は自分だけの問題 | 自分が元気だと家族も職場も元気になる |

## 6. 会話のバージョン（型）

同じテーマでも、型を変えれば何本も作れます。

| 型 | 長さ | 中身 | 向いているテーマ |
|---|---|---|---|
| **A. 基本の対談** | 8〜12分 | Kappyさんの疑問 → 先生の例え話 → 体感ワーク → 今日のひとつ | どのテーマでも |
| **B. ショート** | 30〜60秒 | 思い込み1つ → ひっくり返す → 決めゼリフ | 思い込みの表（5-④） |
| **C. Kappyの1週間チャレンジ** | 連続5〜7本 | Kappyさんが実際に試して、毎日の変化を報告。先生がコメント | 黄金の1週間、タンパク質60g、腹八分目 |
| **D. お悩み相談** | 5〜10分 | 視聴者からの質問をKappyさんが読み、先生が答える | 肩こり、だるさ、眠れない、など |
| **E. 病院とYoshiメソッドの通訳** | 5〜8分 | 「病院でこう言われた」を、Yoshiメソッドの言葉で言い直す（否定ではなく補足） | 検査値、薬との付き合い方 |
| **F. 先生の一日をのぞく** | 5〜10分 | 先生の食事・運動・考え方をKappyさんが取材 | 実践編、イケおじの実例 |
| **G. 振り返り回** | 5分 | シーズン途中で、Kappyさんが学んだことを自分の言葉で話す。先生が補足 | 段階④⑤ |

### 話し方の雰囲気も変えられる
- **掛け合い多め**：Kappyさんのツッコミ・驚きを多めに。ショートやSNS向け
- **落ち着いた対話**：ゆっくり、しみじみ。講義の導入や心の回向け
- **体験重視**：説明は少なく、Kappyさんが体で感じる場面を中心に

## 8. 会話サンプル

### サンプル1：第1話「薬を飲めば大丈夫、じゃないの？」（型A・冒頭部分）

> **Kappy**：今日も頑張らずに！
> **Yoshi**：整えていきましょう。
> **Kappy**：先生、さっそくなんですけど、私、正直「体の調子が悪くなったら病院行って薬もらえばいい」って思ってるんですよ。
> **Yoshi**：うん、それ、すごく大事なことですよ。
> **Kappy**：え、否定しないんですか！？
> **Yoshi**：しないです（笑）。病院は消防隊みたいなもの。火事になったら、すぐ呼ばないと。
> **Kappy**：ですよね！
> **Yoshi**：でもね、Kappyさん。消防隊って、火が出ないように家を作ってくれます？
> **Kappy**：……あ、それはしてくれないですね。
> **Yoshi**：そう。火が出にくい家にしておくのは、住んでいる人にしかできないんです。体も同じで、毎日の暮らしで「病気になりにくい体」にしておくのは、自分にしかできない。
> **Kappy**：ちょっと待って、それメモします。
> **Yoshi**：「健康寿命」って聞いたことあります？
> **Kappy**：長生きのことですよね？
> **Yoshi**：惜しい。長生きは平均寿命。健康寿命は、**自分の足で歩いて、好きなことを楽しめる期間**のことなんです。
> **Kappy**：……それ、私が欲しいのはそっちだ。
> **Yoshi**：でしょう。マラソンで言うと、ゴールまでたどり着くかより、最後まで景色を楽しみながら走れるか、なんですよね。
> （→ 体感ワーク：握りこぶし → 第3話への予告）
> **Yoshi**：今日のひとつ。「病院は消防隊、家づくりは自分」。これだけ覚えて帰ってください。
> **Kappy**：目覚めメーター、まだ1です（笑）。

### サンプル2：ショート（型B）「バランスよく食べればOK？」
