## 一言でいうと

**血を作るのは栄養。カロリーや「バランス」ではなく、細胞レベルで「オートファジー」と「ATP（エネルギー）」がよく働くように食べると、体が元気になり老化を防げる。**

---

## 1. シリーズ内の位置づけ（おさらい）

| 区分 | 見える／見えない | 要点 |
|---|---|---|
| 気虚 | 見えないもの（心） | 思考＝エゴは未来の不安・過去の執着でストレスを生み、エネルギーを消耗する。「今ここ」にいると直感が働く。マッサージ等の「感じる」ことでエゴの声を沈める |
| **血虚** | **見えるもの（体・細胞）** | **血が不足 → 血を作る → そのための栄養（今回）** |
| 気滞 | 流れ | 心：執着がない。体：運動・正しい骨格。姿勢が悪いと神経・血管が圧迫され、栄養が細胞に届かない → マッサージ・整体で正しい骨格に戻す |

見えるもの・見えないものを**滞りなく流せると健康**になる。

## 2. 前提：なぜ従来の栄養学では足りないか

- 戦後の食糧難の名残で、栄養指導が**カロリー中心**になっている
- 「炭水化物◯％・タンパク質◯％・脂質◯％をバランスよく」は、人によって何を基準にするかが曖昧
- ビタミンごとに必要量も吸収量も違う（例：Aは少しで足り、Cは多め・風邪の時はさらに必要）
- → **細胞レベルでどれだけの栄養が必要か**という観点で考える

参考にした考え方
- 分子生物学：**吉森先生**（オートファジー研究）
- 分子栄養学：**三石先生**、**藤川先生**（精神科医。栄養指導で患者を治している）

科学的根拠について：ビタミン・栄養療法は製薬と違って研究予算が付きにくく、大規模な検証が少ない。ただ実際に良くなっている人もおり、先生は「比較的科学的」と考えている。**鵜呑みにせず、自分で考えること**とも強調。

## 3. キーワード①　オートファジー

- **細胞の恒常性**（一定に保つ）を守る働き
- 壊れた・疲れた細胞の中身を、細胞自身が**リサイクル**して作り直す
- たとえ（吉森先生）：**伊勢神宮の式年遷宮**。古くなったものを少しずつ同じように作り直していく
- **加齢**や**高脂肪食**で機能が落ちる → 活性酸素の除去が追いつかず体を傷つける → **老化の原因**

### オートファジーを高める食べ物

| 成分 | 主な食品 |
|---|---|
| ウロリチン | ザクロ、クルミ、ベリー類 |
| スペルミジン | 納豆、味噌、醤油、チーズ、椎茸 |
| カテキン | 緑茶 |
| レスベラトロール | 赤ワイン、ブドウ |
| アスタキサンチン | エビ、鮭 |
| グルコサミン | エビの殻など |

### オートファジーを高める生活

- **カロリーを減らす＝腹八分目**。お腹が鳴って空腹を感じてから食べる
  - 空腹時間が大事（断食が良いと言われる理由）
  - ただし断食しすぎ・野菜だけでエネルギー不足になるのはNG。**エネルギーはきちんと取る**
- 運動
- 睡眠の質

## 4. キーワード②　ATP（エネルギーの最小単位）

細胞内で「発電」する仕組み。3段階で効率が上がる。

| 段階 | 燃料 | 酸素 | ATP（講話での数値） |
|---|---|---|---|
| 嫌気性解糖 | ブドウ糖 | 不要 | 2 |
| 好気性（クエン酸回路など） | ブドウ糖 | 必要 | 38 |
| 脂肪酸の燃焼 | 脂肪酸 | 必要 | 129 |

- 好気性の段階に進むのに必要なもの：**タンパク質・ビタミンB群・鉄**
- パン・菓子パン・ラーメンなど**炭水化物だけ**の食事だと最初の段階で止まる。糖の代謝でビタミンBも使い切り、先に進めない
- → ATP不足 → だるい、ぼーっとする、やる気が出ない、精神的な疲れ
- 体が弱っている人・タンパク質でお腹を壊す人は脂肪燃焼まで行きにくい

## 5. 実践：どう食べるか（先生自身の実践例つき）

1. **糖を減らす**：ご飯・パンを減らす（ゼロにはしない）
2. **タンパク質を増やす**：体重60kgなら1日60g（体重1kgあたり1g）
   - 先生の例：プロテインパウダー 朝20g＋夜20g＝40g、残り20gを鶏肉・卵などで
   - 最低限のタンパク質がないとオートファジーも落ちる
3. **ビタミンB群**：B1・B2・B3などをまとめて取れるサプリ
4. **鉄**：血液検査で必要なら鉄剤。先生は代わりに**プルーン2個**程度
5. **良質な脂質**：オリーブオイル、ちゃんとしたバター。ポテトチップスなど**酸化した油は避ける**
6. **抗酸化**：ビタミンE・C（ナッツ、レモンなど）で活性酸素を除去
7. 夜中の食事を少なくする

> 基礎の栄養さえ押さえれば、あとは好きなものを食べてよい（藤川先生）。食は喜び。楽しむために何をどれだけ取るかを把握する。

## 6. まとめ（締めのメッセージ）

- オートファジーとATPの働きを最大限使える体を作る → 細胞のエネルギーが満たされる
- タンパク質不足＝細胞を修復する材料がない → だるさ・運動しても調子が悪い原因に
- 目指すのは**老化を防ぎ健康寿命を延ばす**こと
- 次回予告：**気滞**（流れ）とマッサージの大切さ

### 内容面で補足を検討したい箇所
- **ATPの数値（2 → 38 → 129）**：教科書的な古い数値。最近の教科書ではブドウ糖1分子あたり約30〜32、脂肪酸（パルミチン酸）は約106とされることが多い。「糖より脂肪の方がずっと多くのエネルギーを生む」という主旨は変わらないので、公開時は「約」を付けるか、注記を入れると安心
- **「オートファジーで同じ細胞を作る」**：正確には細胞そのものではなく、細胞の中身（古くなったタンパク質や小器官）を分解・再利用する仕組み
- **ウロリチン**：食品に直接入っているのではなく、ザクロ・クルミ・ベリーの成分（エラグ酸）から腸内細菌が作るもの
- **赤ワイン**：お酒を勧める表現にならないよう配慮するとよい
- **サプリ・鉄剤**：「医師に相談のうえ」の一言を添えると安全
