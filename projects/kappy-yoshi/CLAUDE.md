# Kappy × Yoshi先生プロジェクト　整理のルール

このフォルダに情報が届いたら、次のルールで整理する。

## 振り分け先
| 届いたもの | 置き場所 |
|---|---|
| 講話・動画の文字起こし（原文） | `transcripts/`（受け取ったまま保存） |
| シリーズ本編（気虚・血虚・気滞など）の講話 | `notes/<番号>-<テーマ>.md` に整理ノート |
| 過去の素材など、一部だけ使うもの | `notes/ref-<名前>-エッセンス.md` に要点だけ抜き出す |
| 登場人物・会話の型・話数・台本に関わる情報 | `notes/会話シリーズ企画書.md` に反映 |
| 配信・トレンド・収益化に関わる情報 | `notes/発信戦略と収益化.md` に反映 |
| 方針の決定、思いつき、まだ置き場所がないもの | `notes/決定事項とアイデア.md` に日付付きで追記 |

整理したら必ず `README.md` の一覧を更新する。

## 守ること
- 現代医学を否定しない。「病院は消防隊、Yoshiメソッドは家づくり」の立場
- 断定しない（「治る」ではなく「整いやすくなる」）。数値には「約」「目安」
- 文字起こしの誤変換は、原文は直さず、ノートの「確認が必要な点」に書く
- Kappyさんの性別は決まっていないので、代名詞を使わず「Kappyさん」と書く
- 書き言葉は分かりやすい日本語で。専門用語には一言説明を付ける
