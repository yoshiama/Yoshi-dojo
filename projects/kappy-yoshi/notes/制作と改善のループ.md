# 制作と改善のループ

**作る → 出す → 反応を見る → 直す** を回していくための記録です。完璧な1本より、早く出して直すほうがうまくいきます（先生の「頑張らない」と同じ）。

---

## 1. 2つの流れを並行して進める

```
【流れA：素材をためる】                   【流れB：動画を作って試す】
先生の過去の動画・講話・本                  台本（scripts/）
        ↓                                        ↓
整理ノート（notes/）                       撮影・公開
        ↓                                        ↓
Kappy向けに翻訳                            反応を見る（この表に記録）
（会話ネタ・例え・ショートの一言）               ↓
        ↓                                  何が刺さったかを企画書に戻す
企画書・話数案に反映 ──────────────→ 次の台本へ
```

## 2. 反応の見方

### 公開後に見る数字
| いつ | 見る数字 | 何が分かるか |
|---|---|---|
| 48時間後 | クリック率（サムネイルとタイトルを見て押した割合） | タイトル・サムネイルが効いているか |
| 48時間後 | 最初の30秒で離れた人の割合 | つかみが効いているか |
| 7日後 | 平均視聴時間・どこで離れたか（視聴維持のグラフ） | どのパートが退屈か、どこが盛り上がったか |
| 7日後 | コメントの中身 | 何が心に残ったか。次回のネタ |
| 7日後 | ショートの再生回数の比較 | どのテーマ・一言が広がりやすいか |
| 30日後 | 登録者の増え方、LINE・メール登録数 | 収益化の入口につながっているか |

### コメントで特に拾うもの
- 「自分のことだ」という共感 → Kappyさんの設定が効いている
- 質問 → 次回のお悩み相談回のネタ
- 「病院を否定している？」という声 → 言い方を見直すサイン

### データの取り方
- YouTubeの管理画面（YouTube Studio）の数字を、この表に書き写してもらえれば分析します
- Instagramなど他のSNSは、つながっているMetricool（SNS管理ツール）から数字を読めるかもしれません（使えるかどうかは要確認）
