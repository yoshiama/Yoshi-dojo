## 1. 講話の基本姿勢（Yoshi先生の言葉から）

- 目的：**病気を薬以外で良くする**考え方を、頭の中に「インストール」する
- **一番怖いのは「体の中で何が起きているか分からない」こと。** 仕組みを知っておけば病気が怖くなくなり、病院（西洋医学）とも冷静に付き合える
- **全部を医師に任せきりにするのは危険。** セカンドオピニオン、サードオピニオンは聞くべき。そのうえで、自分の体に自分で責任を持つ
- 西洋医学の医師を否定しているのではなく、**尊敬している**。どの職業も「今分かっている方法」を提供しているだけで、将来は変わりうる（昔は治らなかったがんも、今は治る人が多い）。体についての考え方も常に新しくしていく
- 薬を使うときは、**副作用を理解したうえで飲む**。軽いうちは食事の改善から始め、薬に頼りきらず、自分の体を客観的に見る
- 知識が入れば、あとは**人生を楽しむ**だけ。お酒も飲んでいい。そのとき一緒に何を食べるかを意識すればいい
- 今に生きて気分良くしていると、必要な情報は自然に入ってくる（→ 禅・著書のRASの話とつながる）

## 2. すべてに共通する原則

講話の最後に先生自身がまとめた結論：**「だいたい同じことを言っている」**

| 原則 | 中身 |
|---|---|
| ① タンパク質が基本 | 血管・軟骨・免疫・ホルモン、すべての材料。まずここ |
| ② 糖質はとりすぎない | 制限ではなく、とりすぎない |
| ③ ビタミンをたっぷり | 特にA・B群・C・E。最初はサプリで補い、いろいろな食品から |
| ④ 活性酸素を消す（スカベンジャー） | 多くの病気の本当の問題は活性酸素。抗酸化の食べ物をとる |
| ⑤ 鉄など | 必要に応じて |
| ⑥ ストレスを減らす・笑う | ストレスは活性酸素を増やし、免疫細胞（NK細胞）を減らす |
| ⑦ 体（整体）と栄養の両方 | 体のねじれ・こりをほぐすことと、食べることのバランス |

## 3. 症状別のまとめ

「病名の常識」→「三石理論の見方」→「栄養」→「Yoshi先生の整体の見方」

| 症状 | よくある常識 | 三石理論の見方 | とるとよいもの | 整体の見方（Yoshi先生） |
|---|---|---|---|---|
| **高血圧** | 減塩 | 減塩が効く人は一部。**ナトリウムとカリウムのバランス**（リンゴ産地は高血圧が少ない）。精製塩の問題という説も。血管の収縮にはカルシウムとマグネシウムのバランス | カリウム、カルシウム（小魚）、マグネシウム（海藻・そば・ごま・ココア）、良質なタンパク質、EPA（イワシ・サバ・マグロ） | ― |
| **コレステロール** | 高いと悪い。悪玉・善玉 | コレステロールは**細胞膜・ビタミンD・ホルモンの材料で必要なもの**。問題は運搬役（リポタンパク）が**活性酸素で壊れる**こと。「悪玉・善玉」は名前による印象 | 抗酸化の食べ物、**レシチン**（卵黄・大豆） | ― |
| **糖尿病** | カロリー制限 | 本当に怖いのは**合併症**（目・神経）。原因は活性酸素。数値が高くても抗酸化の食事をしている人は元気なことがある | 糖質を減らしタンパク質を増やす。カロテノイド（にんじん・かぼちゃ・トマト・緑黄色野菜・柑橘・海藻・魚卵・ごま・緑茶） | ― |
| **動脈硬化** | 年齢で戻らない | 血管の弾力のもと**エラスチン（タンパク質）**の不足 | タンパク質、ビタミンB6（大豆・バナナ・豚肉）、タウリン（牡蠣・魚の血合い）、卵 | **筋肉が硬いと血管の弾力も落ちる → マッサージが効果的** |
| **脳血栓** | 再発しやすい | 血の固まりやすさにはプロスタグランジン（局所ホルモン）が関係 | 血流をよくする。腸をきれいに | マッサージで血流をよくする |
| **痛風** | 尿酸値を下げる | 尿酸が結晶になるのが問題。近くに**糖タンパク**があれば結晶になりにくい | タンパク質、ビタミンA | ― |
| **脂肪肝** | 禁酒 | 脂肪を肝臓から運び出す力の不足 | ビタミンB群、レシチン（豚肉・チーズ・イワシ・マグロ・豆腐・かつお節・そら豆・落花生）。**お酒を飲むときに一緒に食べる** | ― |
| **胃潰瘍・十二指腸潰瘍** | 薬で胃酸を抑える、ピロリ菌の除菌 | ストレス → 交感神経 → 血流低下 → 活性酸素で潰瘍 | タンパク質、ビタミンC、抗酸化 | **左の背中（胸椎上部）が張る。潰瘍になる前にほぐして予防**。奥様（アロマセラピスト）の影響で、抗生物質の代わりにオレガノのカプセルを使うことも（先生個人の例） |
| **風邪** | 薬で治す | ウイルスと戦う物質**インターフェロン**はタンパク質とビタミンCで作られ、温めると作られやすい | タンパク質、ビタミンC、抗酸化。食欲がなければ水分だけで細胞を休ませる（オートファジー） | **風邪は体の左右のアンバランスを整える反応でもある。うまく「通過」させる**。休む → 鼻水が黄色くなる → 便が出て体が緩んで終わる → 前より強くなる。先生は引きそうなとき背骨に気を通す（くしゃみが出て通過する） |
| **アレルギー・花粉症** | 抗ヒスタミン剤 | 免疫が働くハードルが下がっている状態。ヒスタミンは脳でも必要なので全部抑えるのは難しい。栄養で余計な働きを抑える | ビタミンA（ハードルを上げる）、**ビタミンC（ヒスタミンを抑える）**、抗酸化、ビオチン（卵黄・オートミール・大豆など）、イチョウ葉エキス | **年末の疲れで肝臓（右側）が張り、体がねじれる → 胸椎1・7番 → 首（頸椎3・4番）が硬くなり鼻と目に出る。12月から右側のラインをほぐして予防** |
| **不眠** | 睡眠薬 | 眠りを促すセロトニンの材料はトリプトファン（アミノ酸） | 動物性タンパク質 | **首・目の疲れ（首まわりの筋肉）をほぐすと脳の血行がよくなる。足の冷え → フットバス。今に生きる（先生の手の感覚に意識を向ける）** |
| **腰痛・肩こり** | ― | 多くは筋肉性。B群がないと疲労物質がたまる | タンパク質、ビタミンE、レシチン、**ビタミンB群（B1・B2）** | マッサージ、骨格を整える、姿勢 |
| **肝炎（C型など）** | インターフェロン注射 | 体内で作るインターフェロンには副作用がない | ビタミンA・C、タンパク質、グルタチオン（卵のアミノ酸から作られる） | ― |
| **関節炎** | カルシウム | 軟骨・骨はタンパク質が土台。コラーゲン（ビタミンC）、プロテオグリカン（ビタミンA）、ビタミンK、その後にカルシウム | タンパク質、ビタミンC・A・K（ブロッコリー・ピーマン・納豆）、運動の刺激 | ― |
| **関節リウマチ** | ステロイド | 自己免疫。活性酸素が武器になる | ビタミンE・C・A・B群（にんじん、レバー） | ― |
| **貧血** | 鉄剤 | ヘモグロビンはタンパク質（グロビン）＋ヘム鉄 | タンパク質、ビタミンB6・B12・葉酸・C、銅。**タンパク質をとると鉄剤が飲めるようになる** | ― |
| **更年期障害** | ― | 更年期以降は副腎の男性ホルモンが脂肪組織で女性ホルモンに変わる → **やせすぎない方がいい** | 適度な脂肪、ビタミンE・C | **家族の理解が必要。「根性がない」と自分を責めて悪化する。家族がマッサージに行かせてあげる、背中をほぐす** |

## 6. 発信するときに特に気をつけたいこと（重要）

この知識はYOSHIの大事な柱ですが、YouTubeは**医療に関する発信のルールが特に厳しい**分野です。公的な医療機関の見解と食い違う内容は、動画の削除やチャンネルへの警告につながることがあります。発信の仕方で、安全に届けられるかが大きく変わります。

| 安心して話せること | 言い方に工夫が必要なこと | 動画では避けたいこと |
|---|---|---|
| タンパク質・ビタミン・抗酸化の大切さ | 降圧剤・コレステロールの薬・ステロイドの副作用の話（「副作用を理解したうえで、医師と相談しながら」と必ず添える） | 「薬をやめていい」と受け取られる言い方 |
| コレステロールは体に必要な材料、という仕組みの説明 | 「減塩が効く人は一部」などの数字（三石先生の説として紹介し、断定しない） | 「この知識があれば医者はいらない」 |
| 整体の視点（右側の張りと花粉症など） | 精製塩・グルタチオンと国の話（「〜という説もある」程度に） | コロナワクチンと血栓の話（YouTubeで特に厳しく扱われる話題） |
| セカンドオピニオンのすすめ | オレガノを抗生物質の代わりに使う話（先生個人の例として。視聴者にはすすめない） | がんなど重い病気を「食事で治せる」と言うこと |
| 笑う・ストレスを減らす・家族の理解 | 風邪を通過させる話（高熱や長引く場合は受診、と添える） | ― |

**おすすめの伝え方**：「三石巌先生はこう考えました」「整体ではこう見ます」と**視点の一つとして紹介**し、「最終的には自分の体で感じて、医師とも相談しながら選んでください」で締める。これは先生自身の「鵜呑みにしない」「自分の体に責任を持つ」というメッセージそのものなので、むしろ信頼につながります。

### 内容で確認したい点
- **元の本の書名**：講話では「2001年発売」とのこと。三石巌先生は1997年に亡くなっているので、没後の新版の可能性があります。正式な書名を教えていただければ、紹介するときの出典にします
- **「お医者さんが書いている」の部分**：三石巌先生は医師ではなく物理学者として知られています。動画で紹介するときは「物理学者の三石巌先生が提唱した分子栄養学」とするのが正確です
- 本の内容は1990年代の研究が中心のため、その後の研究で見方が変わった部分もあります（例：コレステロールの薬の種類と副作用の考え方）。動画にするテーマが決まったら、その部分は最新の情報と照らし合わせます
